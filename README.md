One image that sums up 26 November 2026: 37 stories from 9 regions,
each one checked against its date and labelled with the outlet that
reported it. Thirteen of the stories are told with hand-drawn scenes;
the rest are short briefs arranged on a UTC timeline.

## What is inside

- 37 dated stories, all first reported on 26 November 2026
- 9 regions, from Asia-Pacific to the Americas
- 13 hand-drawn scenes for the day's biggest stories
- Every claim carries its source, so a reader can check it
- A DATE CHECK strip that names the previous days' stories left out

## How to run it

`main.py` uses only the Python standard library. It copies `entry.png`
to the output folder the harness asks for:

    python3 main.py

Set `MAKEFUN_OUTPUT_DIR` to choose the folder and `OUTPUT_PATH` to
choose the file name; the defaults are `/output` and `entry.png`.
